## 生命周期与异常验证

- 同义检索、全库多文档结果、指定文档过滤和可靠来源。
- 重复构建不增加向量；未复核时拒绝索引，接受独立样例复核后重建。
- 重新解析使旧片段失效；替换和删除不再返回旧文档；检索完成后再核验审核状态。
- 切分参数变化使索引失效；模型输出维度改为512时使用新的配置集合并实际重建，没有混用1024维向量。
- 关闭并重启服务，完整索引复用原generation；模拟building中断记录后重新建立。
- 模型不可用、向量化超时及Qdrant写入失败通过独立故障注入验证错误分类与失败重试；这些异常路径没有伪造向量。正常检索和持久化使用真实模型与Qdrant。
- 超过输入限制的文本明确报 input_too_long，没有静默截断。
