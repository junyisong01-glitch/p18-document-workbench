# 实时检索与原文查看

本轮仅优化阅读方式，API中的原始排名、RRF分数、来源和权限仍由服务端决定；未接入重排序器、未重新切分或向量化，也不使用静态示例替代真实结果。

- 检索页标明当前身份及可见范围。管理员的阅读权限仍受文档ACL限制。
- 卡片保留片段换行，较长文本以6行节选显示；点击查看完整命中证据，不将节选当成完整答案。
- 从检索结果打开默认显示“命中证据”：Word表格按服务端实际行列、合并单元格显示。原文编号、范围保留在可展开的技术信息内。
- “原文件”优先打开服务端已记录的来源页并可翻页；没有映射则从第一页开始并说明。Word转换版式可能变化，不承诺逐字高亮。
- “全文解析”按需查看整份解析结果；全文包含未命中段落，不能当作全部检索证据。Excel可核对原始坐标及已保存值，不执行公式，也未新增原始单元格跳转。
- 来源与下载携带revision、index_token和chunk_id；失效仍由现有服务端拒绝。切换库后过期的查询响应不会重新展示。
- 来源内容始终以React文本渲染，不执行文档内HTML或指令；外发许可及个人Key机制未改。

浏览器验收需独立的本机受权账号与数据，不将真实账号、资料、数据库或浏览器会话提交仓库。后端标准环境446通过4跳过（可选解析/真实本地模型生命周期检查缺省跳过），前端4项来源关系检查通过；Chrome候选界面连接真实本地后端，覆盖五种身份与两库，无AI调用。具体本机验收记录不进入公开仓库。

本改动不等于重新验收整体检索质量；单个问题可找到正确证据，不保证所有问题Top-5都完整。文档版本与被测试软件版本仍分别保留，不用截图的模拟数值或文本覆盖原件事实。
