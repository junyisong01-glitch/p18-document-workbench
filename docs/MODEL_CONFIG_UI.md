# 问答页模型接口配置

正常登录 → 选择演示资料库 → 知识问答 → 右上角“配置模型API”。当前服务为后端实际DeepSeek配置，接口地址和模型名称只读，不支持从网页指定其他服务商。API已配置只表示本次会话保存了格式有效的Key，不表示Key真实有效或余额充足。

- 输入个人Key后保存；输入框清空，状态显示实际模型名。
- “显示密钥”仅显示本次输入的新值，不会获取已保存的Key。
- 配置仅进入原生 `/api/rag/credentials`，与当前登录绑定。应用不写浏览器storage、配置文件或数据库；同一会话刷新可继续用，退出或重启失效。
- 保存/清除会使旧票据失效，界面会撤下原发送预览，需重新核对消息。已有问答进行时后端拒绝改Key。
- “检查配置（不联网）”只读取本机模型配置和检查输入格式，未连接远端模型、未测试余额、未发送资料。
- 问答仍执行原生 drafts → selection → 完整消息与来源预览 → 人工同意 → answer；接收地址、模型、提示词、权限及外发许可不变，未配置Key不生成模拟回答。
- 启辰库保持本地只读、禁止外发，问答页不显示配置入口。Key不会授权任何文档外发。

参考补丁仅用于样式比较，未覆盖原生问答代码。没有采用其中localStorage存Key、浏览器直连任意API、前端重写消息/引用校验、演示回答兜底或失败自动重试。OpenAI、Kimi及自定义模型/地址并未接入。

## 代码

- `frontend/src/components/ModelConfigDialog.tsx`：配置弹窗、显隐、检查、保存、清除及键盘操作。
- `frontend/src/lib/modelConfig.ts`：只调用同源原生凭据/状态接口，不直接调用远程模型。
- `frontend/src/pages/QaPage.tsx`：入口状态与旧确认撤销；保留原生问答和来源逻辑。
- `app/main.py` 中凭据接口、`app/rag.py` 客户端及安全门复用，业务后端未改。
