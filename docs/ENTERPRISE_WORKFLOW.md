# 中型企业权限与流转升级（2026-11-17）

本轮基于用户确认的三项规则：员工保留公司公开和主管明确批准的借阅例外；邀请建号仅老板与人事主管 qichen_hr_head；上传者可声明轻量勘误，保留旧内容和完整审计。历史文档中的“主管不得自审/不得建号”属于升级前规则。

| 身份 | 当前新增能力 | 仍然受限 |
| --- | --- | --- |
| 老板 | 全公司审批、包括自审；邀请员工/访客 | 正常检索及RAG仍不含历史、待审、回收站；启辰资料不可外发 |
| 部门主管 | 本人提交可自审、发布；本部门普通旧资料默认可读；本部门非机密发布件可借阅给明确账号 | 不能自动读机密；不能管理其他部门；不能物理删除 |
| 人事主管 qichen_hr_head | 另有邀请员工/访客建号及重发未激活邀请 | 不能通过建号赋予老板、主管或演示管理员权限 |
| 普通员工 | 提交、查看本人进度、本人已发布件轻量勘误、上传新版 | 无审核/发布/删除权；跨部门仅明确借阅或公司公开 |
| 访客 | 公开与明确获准资料查阅 | 无上传、勘误、审批与管理权；新访客原生身份无部门默认读权 |

## 页面操作

- 在启辰库“文档管理”进入“邀请建号”。邀请24小时有效、仅显示一次；交给本人后在登录页“新人：使用一次性邀请激活账号”设置至少12字符密码，然后正常登录。过期/遗失可重发未激活邀请，旧邀请立即作废；不重置在用账号。新人不会出现在本机演示卡片里。
- 主管在“我的提交/待审核”可以处理本人提交。审批和发布均写当前操作人审计；必要解析复核仍须完成，不能伪造索引就绪。
- 员工在“我的提交/已发布”对本人当前资料使用“轻量勘误”：声明修改性质、填写原因。DOCX普通段落可直接改正文，复杂对象/表格及其他格式上传同格式修正原稿。
- 勘误不走业务审批、业务版本号不变。内部保存一个新来源实体以保持原稿真实性：原内容继续生效，完成真实解析/切分/向量与索引后原子切换；旧实体转历史。若格式要求技术复核，由主管完成解析复核，不增加业务审批。失败保留旧生效版本，可重试解析或取消勘误。
- 原版本状态/授权被并发修改时勘误不会生效，显示冲突原因，请取消后按最新状态重新提交。普通新版V2仍须全量审核、索引就绪和发布，原V1在V2发布前继续生效。
- “知识检索”可选择“高级搜索：包含有权历史版本”。历史结果明确标记，仅查阅原文；不能加入问答。普通搜索和所有RAG接口仍强制当前发布、索引有效及读取权限。
- 物理删除仍是老板限定、先软删、完整ID确认和审计墓碑；409表示状态已变化，必须刷新重新确认，不放宽条件。

## API和持久化

- `POST /api/business/accounts`：老板/指定HR邀请；普通员工或访客，严格部门/岗位字段。
- `POST /api/business/accounts/reinvite`：同权限，仅针对本入口创建且未激活的普通账号。
- `POST /api/library/activate-account`：一次性邀请设密。邀请数据库只存SHA-256摘要；密码沿用原生scrypt。会话、演示口令与邀请不能互相替代。
- `GET /api/business/documents/{id}/editable`、`POST .../correction`、`POST .../correction-file`：服务器验证本人、当前版本、声明和并发版本。
- `POST /api/business/history-search`：本地混合检索的单独历史查阅入口，权限在查询前后及每个分组成员重新检查。
- 新增 `business_profiles.is_demo`（只将原14个明确演示账号标记为演示）；`account_invitations`、`business_edits` 和一个待处理版本唯一索引。既有文档字段仍使用业务JSON；不搬迁SQLite、不重建既有537向量。
- 来源、旧内容和修改原因通过原始文件、旧业务记录、business_edits和business_events串联。轻量勘误继承同一业务版本的公开标记和逐人借阅；重大新版不自动继承。实际新向量只为用户以后新增/勘误资料生成，原30份不重新切分或向量化。

## 关键限制

系统无法判断“一个数字的更改”是错别字还是关键参数改变。本轮按用户确认采用本人声明与完整旧内容审计，不能声称具备自动语义审批。DOCX直接编辑可能重排被改段落的局部字体格式；未实现PDF逐字编辑、电子表格在线编辑或企业SSO。

现有EXT资料在运行库中均标为机密，本轮不改变密级或原岗位例外，故主管数量不会因“普通旧资料放宽”而自动增加。公开/借阅仅改变本地读取范围，不授予外发许可；启辰全员禁止外部AI。演示库个人Key仍仅服务器会话内存，服务重启后须重新配置，配置不自动发请求。生产级撤权竞态等已有安全限制未宣称根治。
