## 实现范围

现有工作台侧栏启用知识检索，同页切换，不另建网站。真实 `/api/search` 返回排名、正文、章节、分数、风险和来源；默认全库 Top-5，可限定文档，长片段可展开。左侧结果与右侧原文各自滚动，右侧复用已有图片预览、翻页和原件下载。PDF 按物理页；Word 只采用可靠映射，不能定位时保留结构位置，用户可以主动从首页浏览，明确说明这不是来源定位。

文档列表与详情采用真实索引状态和失败重试，审核通过或切分完成均不等于可检索。定期刷新约忙碌4秒、空闲10秒、后台20秒，避免重叠请求。点击缓存结果前重新核验解析版本、索引 token 和有效性；服务不可用时清除旧结果。知识问答仍未开放。

主要文件：`web/index.html`、`web/app.js`、`web/search.js`、`web/style.css`；后端只补充列表状态、健康能力、数据目录/前端版本及检索索引 token，未改变审核、解析、切分或向量规则。启动涉及 `app/local_setup.py`、`scripts/launch.py` 及原 `.command`。新增启动/接口/前端逻辑测试和独立样例生成器。
