## PDF / Word 的产生方式

GitHub 连接不支持将 ChatGPT 生成的 ZIP / PDF / DOCX 二进制文件直接传输过来。这条分支包含原始公开文本和可重复生成转换件的脚本，而不是声称上传了那份原 ZIP。

运行 `python -m pip install python-docx reportlab` 再运行 `python 'P18 测试文档/00_使用说明与授权/build_converted_documents.py'` 可生成 6 份**非官方格式转换件**（3 份 DOCX、3 份 PDF）。这些仅是同一公开资料的另一种呈现格式，用于验证解析器，不得冒称源项目官方文件。

GitHub Actions 的 `P18 Test Documents Package` 工作流若成功执行，将自动生成包括转换件的 ZIP 工件。请从 Actions 对应运行记录的 Artifacts 区域下载，前提是仓库允许执行该工作流。
