# 均易 JUNYI — 统一真实前端

统一React页面连接原生P18接口。登录、资料库、检索、来源与问答确认均来自服务端；没有前端固定账号、模拟语料、固定排名或占位下载。

- npm ci / npm run build：构建到web/app，后端根入口和兼容旧书签均显示同一应用。
- 两库通过/api/library/datasets切换，使用服务端Cookie；密级不能代替数据源。
- 文档、状态和统计从当前身份的API返回；其他库统计须切换后加载。
- 30份启辰库只读，候选仅本地查看；6份库保留管理员原生上传、复核与逐份许可机制。
- 问答使用后端默认选证据、最多8组/20000字符、完整消息预览和逐轮同意；不自动发送。
- 原文预览及下载经原服务端授权；Word转换页存在原有分页/高亮限制，Excel保留原行号提取内容。

实际账号、API Key、原始资料、数据库和真实ACL不随源码提供。界面视觉基于用户提供的2d5504d交付包，业务适配以本分支为准；未采用包内AnythingLLM、Docling或默认造数/账号脚本。
