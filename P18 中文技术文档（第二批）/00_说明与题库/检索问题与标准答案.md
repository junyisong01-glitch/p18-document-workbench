# P18 第二批资料：检索测试问题与标准答案

该文件是人工核验 RAG 的答案参照；请**不要把本答案文件上传到 P18 的测试知识库**，以免泄题。
先将 Word 或 PDF 导入并建索引，再从简单检索到跨文档提问。每个问题都要核对 **结论、源文件名、来源片段**。
推荐每篇只导入 Word 或 PDF 其中一种，避免同内容重复影响向量检索。

### 01 · 基础
**问题：** FastAPI 接收文件上传前需要安装什么依赖？为什么？
**参考答案：** python-multipart，因为上传文件是以表单数据发送的。
**应当引用：** 请求文件

### 02 · 基础
**问题：** 为什么 UploadFile 一般比 bytes 更适合处理大文件？
**参考答案：** bytes 会把整个内容放在内存；UploadFile 的 spooled 文件先用内存，过阈值可写入磁盘。
**应当引用：** 请求文件

### 03 · 基础
**问题：** 如何通过 UploadFile 得到用户上传文件的原始文件名和内容类型？
**参考答案：** filename 和 content_type 属性。
**应当引用：** 请求文件

### 04 · 基础
**问题：** 如何在一个请求中同时接收文件与表单字段？
**参考答案：** 使用 File 和 Form；该请求使用表单数据。
**应当引用：** 请求表单与文件

### 05 · 中等
**问题：** 上传文件的接口为什么不能同时按 application/json 方式声明普通 Body 字段？
**参考答案：** 带文件时请求体编码为 multipart/form-data，而不是 application/json；这是 HTTP 编码限制。
**应当引用：** 请求表单与文件；请求文件

### 06 · 基础
**问题：** 官方教程推荐什么方式定义 JSON 请求体？哪些 HTTP 方法通常用于发送数据？
**参考答案：** 用 Pydantic 模型声明请求体；通常 POST、PUT、DELETE 或 PATCH，GET 请求体不推荐。
**应当引用：** 请求体

### 07 · 中等
**问题：** 当请求体有 item 模型和单一数值 importance，怎样把 importance 明确声明为请求体字段？
**参考答案：** 用 Body 显式声明 importance，否则单一数值通常被当作查询参数。
**应当引用：** 请求体多个参数

### 08 · 中等
**问题：** 为什么应先声明 /users/me 再声明 /users/{user_id}？
**参考答案：** 路径操作按顺序匹配，先声明动态路径可能错误地匹配 /users/me。
**应当引用：** 路径参数

### 09 · 基础
**问题：** URL ?skip=0&limit=10 中分别有哪些查询参数？如果声明 int，会怎样处理？
**参考答案：** skip=0 和 limit=10；按声明类型转换并校验。
**应当引用：** 查询参数

### 10 · 中等
**问题：** 如何让 q 查询参数仍可选，同时增加最多 50 字符的校验？
**参考答案：** 保持默认值 None，使用 Query(max_length=50)，可与 Annotated 配合。
**应当引用：** 查询参数字符串校验

### 11 · 基础
**问题：** HTTP 201 和 204 表示什么？204 能否携带响应体？
**参考答案：** 201 表示已创建，204 表示无内容且不能包含响应体。
**应当引用：** 响应状态码

### 12 · 中等
**问题：** 当请求的资源不存在时，如何用 FastAPI 返回 404？
**参考答案：** 抛出 HTTPException(status_code=404, detail=相关说明)。
**应当引用：** 处理错误

### 13 · 基础
**问题：** 官方教程如何推荐编写和执行 FastAPI 测试？
**参考答案：** 使用基于 HTTPX 的 TestClient，安装 httpx，测试函数以 test_ 开头，使用 pytest 与 assert。
**应当引用：** 测试

### 14 · 中等
**问题：** SQLModel 教程为什么选择 SQLite？Session 如何分配？
**参考答案：** SQLite 是一个文件、Python 有集成支持，易运行；以 yield 依赖项为每个请求提供独立 Session。
**应当引用：** SQL关系型数据库

### 15 · 跨文档
**问题：** 同时接收文件与描述字段，随后要做耗时处理时，结合文档应怎样组织接口？
**参考答案：** 接收层使用 File+Form，按 multipart/form-data；轻量同进程任务可用 BackgroundTasks 在响应后执行，文档举例可先返回 HTTP 202，较重任务可用 Celery 类队列。这里是文档联合建议，不证明 P18 已如此实现。
**应当引用：** 请求表单与文件；请求文件；后台任务

### 16 · 跨文档
**问题：** 路由 /items/{item_id} 加可选 q：item_id 和 q 分别应从哪里读取，怎样检查类型和是否必填？
**参考答案：** item_id 是路径参数，可用 int 类型进行转换校验；q 是查询参数，默认值 None 表示可选。
**应当引用：** 路径参数；查询参数

### 17 · 跨文档
**问题：** 创建资源返回 201 与资源不存在返回 404，各自对应什么机制？
**参考答案：** 路径操作装饰器的 status_code 可指定 201；HTTPException 可返回 404 及 detail。
**应当引用：** 响应状态码；处理错误
