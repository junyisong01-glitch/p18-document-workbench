# P18 中文技术文档（第二批）

**这里有 13 篇完整中文技术说明，不是空白模板。** 来源为 FastAPI 官方公开 GitHub 仓库，采用 MIT 许可。
原始 Markdown 保留逐文件 SHA 与网页来源；另生成 Word/PDF 用于上传 P18 解析与 RAG 测试。

## 文件夹
- 01_上传与请求：请求文件、请求表单与文件、请求体、请求体多个参数
- 02_接口参数与校验：路径参数、查询参数、查询参数字符串校验、响应状态码、直接返回响应
- 03_后端任务与数据库：后台任务、SQL关系型数据库
- 04_错误处理与测试：处理错误、测试
- 00_说明与题库：原始来源、许可、生成脚本、19 道题及答案

## 建议上传
先选 `请求文件_阅读版.docx`、`请求表单与文件_阅读版.pdf`、`后台任务_阅读版.docx`、`处理错误_阅读版.pdf`、`测试_阅读版.docx`。
